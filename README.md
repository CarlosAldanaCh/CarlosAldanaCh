### Age Estimation — ResNet50

### Gold Recovery Prediction — Industrial ML

Modeled two recovery targets. Selection cross-validation sMAPE was 6.47% for the final target with Random Forest and 6.84% for the rougher target with Decision Tree. Combined sMAPE was 6.57%, compared with 11.29% for the combined mean-prediction Dummy baseline, using weights of 25% Rougher and 75% Final. Models were selected using those same folds. Held-out test sMAPE is not reported in the notebook.

[Repository and notebook](https://github.com/CarlosAldanaCh/Zyfra-gold-recovery-machine-learning-)

### Used Car Price Prediction — Rusty Bargain

Compared regression models for price prediction and measured training and prediction times. The README reports LightGBM test RMSE of approximately 1,419 versus 2,445 for the linear baseline. Timing results depend on the execution environment.

[Repository and results](https://github.com/CarlosAldanaCh/Rusty_bargain_car_price_prediction)
